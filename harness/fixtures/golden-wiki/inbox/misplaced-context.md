# 검수 단계를 선언하고 inbox에 남은 문서

이 문서는 inbox 디렉토리에 있으면서 context 단계를 선언한다. 선언이
위치보다 높은 방향의 불일치다. 검수된 지식의 필드 집합을 갖추고
색인 자격을 주장하므로 승급 파이프라인을 우회한다. 위치 규칙이 이
방향을 error 로 잡는다.

정리가 끝난 문서라면 engram promote 로 context 디렉토리로 옮긴다.
