# 낮은 단계를 선언하고 context에 남은 문서

context 디렉토리에 있으면서 artifact_stage 를 inbox 로 적은 문서다.
선언이 위치보다 낮은 방향의 불일치라 경고로 알린다.

게이트는 선언이 아니라 문서가 놓인 디렉토리로 발동한다. 이 문서의
위키링크는 하나뿐이므로 min_wikilinks 에 못 미쳐 거절된다. 선언을
낮춰 검수 단계의 관문을 우회할 수 없다.
