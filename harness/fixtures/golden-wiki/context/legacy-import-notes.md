# 오래된 자료 이관 기록

예전 저장소에서 이관한 자료를 정리하며 남긴 기록이다.
원본 작성일은 연월까지만 알 수 있어 created 는 연월 형식으로 남긴다.

이관할 때 밟은 문제는 두 가지였다.

- 날짜가 없는 문서가 많았다. 지어내지 않고 연월까지만 기록했다.
- 링크가 깨진 문서가 많았다. 대상을 확인할 수 있는 것만 연결했다.

남은 정리 대상은 [[sqlite-foreign-keys|외래 키 노트]] 와
[[cli-flag-conventions]] 다.
