# docs/course/

강의 자료. 슬라이드, 실습, 핸즈온.

**공개 자산이다.** 사내 사례나 조직 맥락은 담지 않는다. 그런 내용은 Enterprise 저장소로 옮긴 뒤 거기서 덧붙인다.

뼈대는 [../curriculum.md](../curriculum.md).

## 파일

| 파일 | 내용 | 상태 |
|---|---|---|
| `index.html` | 1세션 오리엔테이션 덱. LLM wiki 원론, 이 체계의 특별한 점, 해결 방향, engram의 역할, 개인에서 조직으로. 36장, 60분 | 초안 |
| `hands-on.md` | 핸즈온 실습 진행서. 실습 단계 여덟의 결정과 용어. **단계별 HTML 자료의 원본** | 1, 2, 3단계 확정 |
| `agent-start.md` | 혼자 하는 사람용 시작 문서. 커맨드를 치지 않고 에이전트에게 시킨다. 30분 | 작성 |

두 문서는 대상이 다르다. `hands-on.md`는 **강사가 있는 자리**용이며 수강생이 커맨드를 직접 친다. 도구가 무엇을 강제하는지 눈으로 보게 하는 것이 목적이다. `agent-start.md`는 **혼자 하는 사람**용이며 에이전트에게 말로 시킨다. 실무 동선이 그쪽이기 때문이다.

**절차를 두 곳에 적지 않는다.** `agent-start.md`는 여덟 단계를 다시 쓰지 않고 한 바퀴만 돌린다. 자세한 것이 필요하면 `hands-on.md`로 보낸다.

`hands-on.md`가 실습 자료의 진실원이다. HTML을 먼저 만들지 않는다. 단계를 하나씩 확정해 이 문서에 적고, 확정된 것만 HTML로 옮긴다. 용어와 실습 위키 구성 같은 전 단계 공통 결정도 이 문서가 갖는다.

`index.html`은 단일 파일이며 외부 자원을 받지 않는다. 브라우저로 열면 슬라이드 모드로 시작하고, 상단의 읽기 모드 버튼(또는 `R`)을 누르면 스크롤 문서로 바뀌며 각 슬라이드 아래 강사 노트가 펼쳐진다. 슬라이드 모드에서는 `N`으로 노트를 옆에 띄운다. 시연 슬라이드의 터미널은 Space를 누를 때마다 커맨드 하나씩 진행되며, 실린 출력은 `README.md`의 실제 실행 결과와 같다.

## 규칙

- 사내 식별자를 쓰지 않는다. 운영 중인 위키는 "upstream"이라고만 부른다.
- 한국어 산문에 em dash, 화살표, 가운뎃점, 말줄임표, smart quote를 쓰지 않는다. 도식 안의 화살표와 코드 블록은 예외다.
- 커맨드 출력을 실을 때는 실제 실행 결과를 그대로 옮긴다. 지어내지 않는다.

## 남은 것

- 2세션부터 6세션까지의 핸즈온 자료. 커리큘럼의 강의 세션 표를 따른다.
- 데모 위키(`examples/`)가 채워지면 시연 슬라이드를 그 위키 기준으로 다시 찍는다.
