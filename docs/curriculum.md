# 교육 커리큘럼 뼈대 (초안)

> 2026-08-08. 강의 단위/일정은 미정, 수강생 여정만 우선 정리.

## 수강생 여정 (학습 목표)

교육 종료 시 수강생이 갖는 것:

1. 자기 wiki 저장소를 `init`으로 세팅한다.
2. 일상 입력을 `capture`로 inbox에 담는다.
3. 원본을 `source`로 보존하고, 검수된 지식을 `promote`로 context로 올린다.
4. `search` / `recall`로 지식을 회수해 업무에 쓴다.
5. `resurface` / `bridge`로 잊힌 지식을 재발견한다.

## 강의 단위 (가안)

| 단위 | 주제 | 실습 |
|---|---|---|
| 1 | LLM wiki 패턴: RAG와의 차이, 왜 승급인가 | — |
| 2 | 캡처와 원본 보존 (inbox/sources) | capture/source |
| 3 | 승급 게이트 (promote, 스키마) | promote/lint |
| 4 | 회수: 검색과 recall | search/recall |
| 5 | 재발견 루프 | resurface/bridge |
| 6 | 에이전트 연동 | skills install |

## 미결정

- 강의 길이/횟수/대상자
- 평가 방식
- 데모 위키 시나리오 (`examples/`)
