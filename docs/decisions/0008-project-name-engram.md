# 0008 프로젝트 명칭

## 결정

프로젝트 이름을 `engram`으로 확정한다. 폴더는 `~/Git/engram`, 저장소는 `neocode24/engram`, 기본 브랜치는 `main`이다. 이전 명칭은 `llm-wiki-edu`였다.

## 근거

engram은 기억이 뇌에 남기는 물리적 흔적을 가리키는 신경과학 용어다. second brain을 표방하는 도구의 실체를 이름이 그대로 설명한다. 은유가 한 겹이고 설명이 필요 없다.

이전 명칭 `llm-wiki-edu`는 세 가지 문제가 있었다. upstream 저장소 이름에 종속되어 독립 제품으로 읽히지 않고, `-edu` 접미사가 교육 전용이라는 인상을 주어 일반 사용 경로를 닫으며, 발음되지 않는 이름이라 구두 홍보에 쓸 수 없다.

### 기각된 후보

| 후보 | 기각 사유 |
|---|---|
| `arbor` | AI 코딩 도구 인접 영역에 동명 프로젝트가 다수 존재 |
| `loam` | 건강식품 브랜드가 검색 결과를 점유 |
| `bonsai` | 동명 오픈소스가 과다 |
| `trellis`, `lattis` | 격자 은유는 정확하나 사용자에게 와닿지 않음 |

기각 기준은 두 가지였다. 검색 시 이 프로젝트가 첫 페이지에 오를 수 있는가, 그리고 이름을 처음 듣는 사람이 도구의 성격을 유추할 수 있는가.

## 결과

- ADR 0001과 0002의 본문은 소급 수정하지 않고 "당시 명칭 `llm-wiki-edu`" 병기만 추가했다. 소급 수정 금지 원칙을 따른다.
- 실행 파일명, 설정 디렉토리(`~/.config/engram`, Windows는 `%APPDATA%`), 환경변수 접두사(`ENGRAM_`), 커맨드 이름이 모두 이 명칭을 따른다.
- upstream `llm-wiki`의 관련 문서 내 명칭을 갱신했다.
- 설계 논의용 스킬의 reference 파일명을 `engram-design-notes.md`로 개명했다.
