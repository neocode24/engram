# 위키 경로를 받는 방식이 커맨드마다 달랐다

## 배경

[0052](0052-agent-prepares-the-promotion-and-the-human-decides-it.md)로 스킬 문서를 고친 뒤 실제 에이전트에게 승급 준비를 시켜 봤다. 중간에 이렇게 막혔다.

```
engram lint --json --wiki ~/engram-wiki
Error: unknown flag: --wiki
```

세어 보니 커맨드 스물이 `--wiki`를 받고 넷만 위치 인자로 받는다.

| `--wiki` 플래그 | 위치 인자 |
|---|---|
| capture, source, update, promote, demote, archive, new, mv, search, recall, backlinks, digest, resurface, bridge, rules show, export, eject, serve, migrate, sync, mcp | **lint, status, reindex, doctor** |

스킬 문서의 예시 네 곳이 전부 `--wiki`를 쓴다. 에이전트가 그것을 전 커맨드에 통하는 규약으로 읽는 것이 자연스럽다.

## 판단 근거

**사람은 `cd`로 피해 가고 에이전트는 못 피한다.** 사람은 위키 안에서 커맨드를 치므로 경로를 줄 일이 드물다. 에이전트는 셸 작업 디렉토리가 어디인지 모르는 채로 커맨드를 만들기 때문에 매번 경로를 명시한다. **이 불일치는 에이전트만 밟는다.** 그래서 지금까지 안 드러났다.

**한쪽으로 없애는 것은 못 한다.** 위치 인자를 없애면 `engram lint .`이 깨진다. `--wiki`를 스물에서 없애면 훨씬 더 깨진다. 릴리스 전이지만 문서와 골든과 harness가 전부 현재 표기를 쓴다.

**둘 다 받는 것이 비용이 가장 작다.** 넷에 플래그를 더하면 스물넷 전부가 `--wiki`로 통한다. 기존 위치 인자는 그대로 동작한다. 공유 헬퍼 하나와 커맨드당 두 줄이다.

**둘 다 주면 거절한다.** 우선순위를 정해 조용히 하나를 고르면 사용자가 다른 위키를 검사하고도 모른다. 경로가 둘이면 의도가 불명확하다는 뜻이므로 거절이 맞다.

```
Error: 위키 경로를 위치 인자와 --wiki 둘 다로 주셨습니다
어느 쪽을 뜻하는지 알 수 없으니 하나만 남겨 주세요
```

**반대 논거를 검토했다.** 같은 것을 받는 길이 둘이면 표면이 넓어지고 문서가 갈린다는 것이다. 맞는 지적이다.

그러나 이미 갈려 있다. 지금은 **커맨드마다 다른 방식**이라 사용자가 커맨드별로 외워야 한다. 바꾼 뒤에는 **모든 커맨드가 두 방식을 다 받으므로** 아무것도 외울 필요가 없다. 표면은 늘지만 규칙은 줄어든다.

## 결정

`lint`, `status`, `reindex`, `doctor`에 `--wiki`를 더한다. 위치 인자는 그대로 둔다.

경로 선택은 공유 헬퍼 `pathOrWikiFlag` 하나가 한다. 판정을 커맨드마다 두면 한쪽만 고치는 사고가 난다([0045](0045-explicit-slug-must-still-be-filesystem-safe.md)와 같은 근거다).

| 준 것 | 쓰는 경로 |
|---|---|
| 아무것도 없음 | `.` |
| 위치 인자만 | 그 값 |
| `--wiki`만 | 그 값 |
| 둘 다 | 거절 |

## 결과

- `engram lint --wiki <경로>`가 동작한다. 스킬 문서의 표기가 전 커맨드에 통한다.
- 기존 표기가 깨지지 않는다. `engram lint <경로>`와 `engram lint`는 그대로다.
- 회귀 시험을 더했다. 넷 각각에 대해 두 표기가 **같은 출력을 내는지**와 **둘 다 주면 거절하는지**를 본다. **변이 시험으로 검증했다.** 수정을 되돌리니 여덟 부분 시험이 전부 실패했다.

## 열린 항목

- `init`만 대상 경로를 위치 인자로 받고 `--wiki`가 없다. 아직 없는 위키를 만드는 커맨드라 성격이 다르고, 에이전트의 쓰기 경계 밖이라 이 결정에 넣지 않았다. `--wiki`가 "이미 있는 위키"를 뜻한다면 그 자리에 없는 것이 옳다는 판단이며, 뒤집을 근거가 나오면 그때 본다.
