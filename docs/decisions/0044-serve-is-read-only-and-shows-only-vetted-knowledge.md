# serve의 노출 범위

## 배경

`docs/design.md`가 열린 항목으로 남겨 둔 문장이다.

> `serve` 웹 UI의 쓰기 범위. 웹에서 직접 파일을 쓰지 않고 제안으로 접수하는 방식을 검토 중이다.

여정 15가 이 커맨드의 자리를 정했다. "개인 위키 **일부**를 팀과 공유한다." 무엇이 그 일부인지가 정해지지 않았다.

MCP를 먼저 만들면서 인접한 판단이 하나 끝났다([0043](0043-mcp-exposes-one-write-tool-and-omits-promote.md)). 쓰기 도구는 `capture` 하나이고 `promote`는 내보내지 않는다. `serve`는 그것과 성격이 다르다. **MCP는 로컬 프로세스가 stdio로 붙고 `serve`는 네트워크에 뜬다.**

## 판단 근거

### 네트워크 표면에 쓰기를 두지 않는다

"제안으로 접수하는 방식"을 검토했으나 접수함은 쓰기의 완곡한 형태다. 인증 없는 서버에 접수함을 두면 그 접수함이 곧 쓰기 경로이고, 인증을 붙이면 사용자 관리와 자격증명 저장이 따라온다. **engram은 자격증명을 저장하지 않는다는 자세를 지켜 왔다**([0014](0014-llm-boundary-agent-drives-binary.md)).

읽기 전용으로 두면 다른 것이 따라온다. **네트워크 표면에 쓰기가 없으면 인증이 없어도 파괴적 피해가 없다.** 관리할 것이 노출 범위 하나로 줄어든다.

쓰기 경로는 CLI와 MCP 둘이며 둘 다 로컬 프로세스다. 경로를 늘리지 않는다.

### 검수된 지식만 보여준다

여정 15의 "일부"가 무엇인지는 이 저장소가 이미 답을 갖고 있다. **`context/`에 올라간 것이 검수된 지식이고 그것만 남에게 보인다.** 게이트를 지난 것만이다.

`inbox/`는 미검수 러프 캡처다. `sources/`는 원본 보존 계층이라 가공되지 않은 원자료를 담는다. 둘 다 남에게 보여줄 것이 아니며, 보여주면 승급 파이프라인이 웹에서 무의미해진다.

이 결정은 게이트의 의미를 한 층 더 살린다. 지금까지 게이트를 지나서 얻는 것은 검색 대상이 되는 것이었는데, 여기서 **팀에 보이는 것**이 더해진다.

`archive/`는 수명이 끝난 문서다. 기본으로 감추되 링크로 도달할 수 있어야 하는 경우가 있으므로 플래그로 연다.

### 민감도 선언을 도구가 뒤집지 않는다

`sensitivity` 축이 켜진 위키에서 `private-local-only`는 이름 그대로 로컬 전용이고 `restricted`는 제한 공개다. **네트워크로 내보내면 그 선언이 무의미해진다.**

둘을 제외한다. **플래그로 뒤집지 않는다.** 값을 붙인 사람의 판단을 도구가 덮을 이유가 없고, 뒤집는 플래그가 있으면 그 플래그가 사고 경로가 된다. 내보내야 하면 문서의 값을 고치는 것이 옳은 순서다.

축이 꺼진 위키에서는 거를 값이 없다. 사용자가 민감도를 구분하지 않기로 한 상태이며 기본 바인딩이 로컬이므로 문제가 되지 않는다.

### 기본은 로컬 바인딩이다

기본이 전체 노출이면 사고가 난다. `127.0.0.1`로 뜨고 외부 노출은 사용자가 명시한다. **명시할 때 무엇이 노출되는지 알린다.**

### 빌드 체인을 들이지 않는다

작성자의 공통 UI 규칙은 Tailwind CSS를 쓴다. 여기서는 따르지 않는다.

Tailwind는 npm 빌드 체인을 요구한다. **단일 바이너리와 무의존이 이 제품의 근간이고** CI에 node가 들어오며 릴리스 파이프라인이 복잡해진다. CDN을 쓰면 실행 시 네트워크가 필요해져 여정 17(폐쇄망)의 합격 기준을 깬다.

정적 자산을 바이너리에 임베드하고 손으로 쓴 CSS를 쓴다. **나머지 UI 규칙은 그대로 지킨다.** 이모지 금지, ARIA 레이블, WCAG 2.1 AA, 모바일 우선이다.

서버 렌더링으로 충분하다. 위키 뷰어는 문서를 읽고 링크를 따라가는 물건이며 SPA가 필요하지 않다. 검색도 폼 제출로 된다.

**마크다운 렌더러는 goldmark를 쓴다.** 실측으로 의존 모듈이 자기 자신 하나뿐이다. 지금 `blackfriday`가 `go.mod`에 있으나 cobra의 man 생성 경로이고 바이너리에 링크되지 않는다.

## 결정

**`engram serve`는 읽기 전용 웹 뷰어다. 쓰기 경로를 두지 않는다.**

| 항목 | 값 |
|---|---|
| 쓰기 | **없다.** 제안 접수도 두지 않는다 |
| 기본 노출 | `context/`와 `root_files` |
| 기본 제외 | `inbox/`, `sources/` |
| `archive/` | 기본 제외. 플래그로 연다 |
| 민감도 | 축이 켜져 있으면 `private-local-only`와 `restricted` 제외. **뒤집는 플래그를 두지 않는다** |
| 바인딩 | 기본 `127.0.0.1`. 외부 노출은 명시하며 그때 무엇이 노출되는지 알린다 |
| 인증 | 없다. 쓰기가 없고 기본이 로컬이라 성립한다 |
| 자산 | 바이너리에 임베드. npm 빌드 체인을 두지 않는다 |
| 렌더 | 서버 렌더링. goldmark |

- 보여주는 것은 문서 읽기, 검색, 위키링크 이동, 백링크, 위키 현황이다.
- 재발견 커맨드를 노출하지 않는다. 상태를 쓰거나 사람의 판단 기록을 건드린다([0028](0028-rediscovery-state-and-boundaries.md)).
- 판정과 검색은 `internal/` 패키지를 그대로 부른다. 두 벌 두지 않는다.
- 제외된 문서를 가리키는 위키링크는 링크로 만들지 않는다. **경로가 새면 제외가 무의미해진다.**

## 결과

- 게이트를 지나는 것의 의미가 하나 늘어난다. 검색 대상이 되고, 팀에 보인다.
- 인증을 만들지 않으므로 자격증명 저장 책임이 생기지 않는다.
- 팀에 자료를 보여주려면 승급해야 한다. 우회로가 없다.
- 작성자의 공통 UI 규칙 중 Tailwind 항목을 이 저장소가 따르지 않는다. 근거를 여기 남긴다.
- 의존 모듈이 하나 는다. goldmark다.
- 외부 노출을 켠 사용자는 `context/`의 내용이 인증 없이 읽힌다는 사실을 안다. 그 이상의 보호는 이 도구의 범위가 아니며 역방향 프록시의 일이다.
- `pack`(여정 14)이 같은 민감도 판단을 쓴다. 이 ADR의 제외 규칙을 진실원으로 삼는다.
