# --limit을 줄이면 다른 조각이 나왔다

## 배경

핸즈온 5단계를 쓰려고 `recall`을 실제 위키에 돌리다가 드러났다. 같은 질의에 `--limit`만 바꿨는데 1위가 달라진다.

```
--limit 1   rank 1  score 6   배포-설정-키-사건
--limit 3   rank 1  score 7   2026-02-18-캐시-무효화를-설계하는-네-가지-방법
--limit 5   rank 1  score 11  2026-03-04-응답-지연-회의-전사
```

**조각 하나만 달라는 요청이 가장 좋은 조각을 못 받는다.** `--limit 5`가 11점짜리를 1위로 내는데 `--limit 1`은 6점짜리를 낸다.

원인은 한 줄이다.

```go
scored, err := scoreChunks(root, ix.Search(query, limit), query)
```

`--limit`을 **문서 후보 수**로 그대로 넘기고 있었다. `--limit 1`이면 BM25 1위 문서 하나만 훑고 그 안에서 가장 좋은 조각을 낸다. **2위 문서에 더 높은 점수의 조각이 있어도 보지 못한다.**

CLI의 `recall`과 MCP의 `recall` 도구가 같은 코드를 두 벌 갖고 있어 둘 다 같은 결함이었다.

## 판단 근거

**문서 점수와 조각 점수는 다른 척도다.** 문서 BM25는 문서 전체의 길이로 정규화하므로 질의어가 옅게 퍼진 긴 문서가 높게 나올 수 있다. 조각 점수는 한 절 안의 밀도를 본다. **50위 문서가 최고의 조각을 갖고 있을 수 있다.**

그러므로 문서 후보를 자르는 어떤 상한도 근사다. 정확하려면 전 문서를 훑어야 하는데 `scoreChunks`가 후보마다 파일을 읽으므로 수천 문서 위키에서 비용이 실재한다.

**그래도 지금 동작은 근사가 아니라 결함이다.** 근사라면 `--limit`을 바꿔도 상위 순위가 유지되어야 한다. 지금은 `--limit`이 후보 집합 자체를 바꾸므로 **같은 질의의 답이 요청 개수에 따라 달라진다.** 사용자가 통제할 수 없는 방식으로 결과가 흔들린다.

**상한을 `--limit`에서 떼면 그 흔들림이 없어진다.** 후보 집합이 고정되므로 `--limit N`은 언제나 같은 순위의 앞 N개다. 근사라는 성질은 남지만 예측 가능해진다.

**값은 50으로 둔다.** 기본 `--limit`이 5이므로 열 배다. 이 저장소가 지금 측정한 규모(5000문서에서 `reindex` 0.38초)에서 파일 50개를 읽는 비용은 무시할 만하다. 근거 없는 정밀함을 주장하지 않고 상한이라는 사실을 코드 주석에 적는다.

**반대 논거를 검토했다.** 후보를 아예 안 자르면(전 문서) 근사가 사라진다는 것이다.

기각한다. 비용이 문서 수에 선형이고 `recall`은 에이전트가 반복해서 부르는 커맨드다. 그리고 상한을 없애도 **조각 점수 자체가 근사**라 완전한 정답이 나오는 것도 아니다. 필요가 생기면 값을 올리면 되고 그때는 근거를 측정으로 댄다.

## 결정

`recallCandidateDocs`를 50으로 고정하고 `ix.Search`에 `--limit` 대신 이 값을 넘긴다. `--limit`은 조각을 점수순으로 정렬한 뒤에만 적용한다.

CLI와 MCP 양쪽에 같은 값을 쓴다.

## 결과

- `--limit`을 바꿔도 상위 순위가 유지된다. `--limit 1`이 `--limit 10`의 1위와 같다.
- 회귀 시험을 더했다. 질의어가 옅게 퍼진 문서와 한 절에 몰린 문서를 두고, `--limit` 1, 2, 3의 결과가 전체 목록의 앞부분과 같은지 본다. **변이 시험으로 검증했다.** 후보 수를 `--limit`으로 되돌리니 `--limit 1`의 1위가 달라져 실패했다.
- MCP `recall` 도구도 같이 고쳐졌다.

## 열린 항목

- `recall`의 코드가 CLI와 MCP에 두 벌이다. 이번에 같은 결함이 양쪽에 있었고 양쪽을 따로 고쳤다. 합칠지는 별개 결정이다.
- 조각 점수 계산 자체는 아직 parity 비교 축이 아니다. 문서 검색 순위만 [ADR 0005](0005-upstream-contract-and-harness.md)의 비교 대상이다.
