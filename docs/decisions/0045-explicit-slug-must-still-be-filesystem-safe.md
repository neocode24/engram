# 명시 슬러그의 안전 검사

## 배경

ADR [0020](0020-slug-and-filename-rules.md)이 슬러그 파생 규칙 다섯을 정했다. 그중 넷째가 "파일시스템에서 문제가 되는 문자와 Windows 예약 파일명을 제거한다"이다. 같은 ADR이 한 줄을 덧붙였다.

> 사용자는 언제든 슬러그를 명시해 파생을 덮어쓸 수 있다.

지금 구현은 명시한 슬러그에 대해 경로 구분자만 막는다. 나머지 넷은 통과한다. 실측이다.

| `--slug` 값 | 만들어진 파일 | 문제 |
|---|---|---|
| `a:b` | `2026-08-17-a:b.md` | **Windows에서 만들 수 없는 이름** |
| `CON` | `2026-08-17-CON.md` | Windows 예약 장치명 |
| `trailing.` | `2026-08-17-trailing..md` | Windows가 끝의 점을 지운다 |
| `공백 있는 슬러그` | `2026-08-17-공백 있는 슬러그.md` | 규칙 둘을 어긴다 |

전부 종료 코드 0으로 통과하고 `lint`도 잡지 않는다.

노출이 최근에 넓어졌다. ADR [0043](0043-mcp-exposes-one-write-tool-and-omits-promote.md)이 MCP의 `capture` 도구에 `slug` 인자를 두었으므로 **이제 에이전트가 이 값을 정한다.** 사람이 플래그를 치는 경우보다 검증되지 않은 값이 들어올 자리가 넓다.

## 판단 근거

**파생을 덮어쓰는 것과 안전을 덮어쓰는 것은 다르다.** 0020의 한 줄은 사용자가 원하는 이름을 쓰게 하려는 것이지, 만들 수 없는 파일을 만들게 하려는 것이 아니다. 규칙 하나부터 셋(소문자, 하이픈 정규화)은 취향이고 규칙 넷은 제약이다.

**Tier 1에 Windows가 있다.** ADR [0007](0007-platform-and-distribution.md)이 windows/amd64를 Tier 1으로 두었다. macOS에서 만든 위키를 Windows에서 체크아웃할 수 없으면 그 계약이 깨진다. 위키는 git으로 두 기계를 오가는 물건이다(여정 13).

**조용히 고치지 않고 거절한다.** 사용자가 이름을 명시한 것은 그 이름을 원한다는 뜻이다. 도구가 말없이 다른 이름으로 바꾸면 사용자가 기대한 위키링크가 안 맞는다. **무엇이 문제이고 무엇으로 바꾸면 되는지 알리고 멈춘다.**

**소문자와 하이픈은 강제하지 않는다.** 파생에는 적용되지만 명시한 값에는 적용하지 않는다. 한글 슬러그를 보존하기로 한 것과 같은 결의 판단이며, 대문자나 공백이 파일을 못 만들게 하지는 않는다. 0020의 그 한 줄이 살아 있는 자리다.

**검사의 진실원을 하나로 둔다.** 파생 경로와 명시 경로가 같은 검사를 부른다. 두 벌로 두면 한쪽만 고치는 사고가 난다.

## 결정

**명시한 슬러그도 파일시스템 안전 검사를 받는다. 어기면 거절한다.**

| 검사 | 파생 | 명시 |
|---|---|---|
| 소문자로 내림 | 적용 | 적용하지 않음 |
| 공백과 구분자를 하이픈으로 | 적용 | 적용하지 않음 |
| 연속 하이픈 정리 | 적용 | 적용하지 않음 |
| **파일시스템 위험 문자** | 적용 | **거절** |
| **Windows 예약 파일명** | 적용 | **거절** |
| 한글 보존 | 적용 | 적용 |

- 거절 메시지는 어느 문자가 문제인지와 어떻게 고치면 되는지를 함께 낸다.
- 검사 함수는 하나이며 파생과 명시 양쪽이 그것을 부른다.
- CLI의 `--slug`와 MCP `capture` 도구의 `slug` 인자가 같은 검사를 받는다.
- 이미 만들어진 파일을 고치지 않는다. `mv`가 이름을 바꾸는 정상 경로다.

## 결과

- macOS에서 만든 위키가 Windows에서 열린다. Tier 1 계약이 지켜진다.
- 에이전트가 MCP로 만들 수 있는 파일명이 좁아진다. 노출 표면이 넓어진 만큼 검사가 따라간다.
- 전에 통과하던 입력이 거절된다. 그 입력으로 만들어진 파일이 이미 있으면 `lint`가 잡지 않으므로 사람이 `mv`로 정리한다.
- 0020의 "언제든 명시해 덮어쓸 수 있다"는 문장이 좁아진다. 파생은 덮어쓰되 안전은 못 덮는다.
